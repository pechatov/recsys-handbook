# Contributing

Проект пока находится на раннем этапе. Главная задача ближайших изменений -
зафиксировать структуру учебника и стиль материалов.

## Как предлагать изменения

1. Создайте отдельную ветку от `main`.
2. Для текстовых правок меняйте файлы в `docs/`.
3. Для интерактивных примеров добавляйте компоненты в `src/`.
4. При изменении программы курса синхронно обновляйте `README.md` и
   `docs/program.mdx`.
5. Перед pull request запустите проверки:

```bash
pnpm check
```

## Стиль материалов

- Начинайте главу с задачи, а не с алгоритма.
- Добавляйте минимальные примеры данных.
- Показывайте ограничения метода рядом с его преимуществами.
- Не прячьте инженерные компромиссы: latency, freshness, bias, leakage и
  monitoring важны так же, как offline-метрики.
- Ссылки на статьи и книги лучше добавлять в конце главы отдельным блоком.
