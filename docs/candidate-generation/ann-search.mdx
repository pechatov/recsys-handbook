# 3.5. Приближённый поиск ближайших соседей (ANN)

:::note[Черновик]
Это заглушка: ниже зафиксирован план содержания лекции. Текст будет написан
позже.
:::

## Что должно быть в лекции

- Задача: найти top-K ближайших векторов среди миллионов за единицы
  миллисекунд; почему точный перебор не масштабируется.
- Основной trade-off: recall индекса vs QPS vs память.
- Семейства методов: LSH, деревья, графовые индексы (HNSW), инвертированные
  списки (IVF), квантизация (PQ, OPQ) и их комбинации.
- Инструменты: Faiss, ScaNN, hnswlib, векторные базы данных — когда что брать.
- Тюнинг индекса: ключевые параметры, методика замера recall@K vs latency.
- Эксплуатация: обновление индекса, добавление свежих айтемов, фильтрация по
  атрибутам при поиске (filtered ANN).
- Практика: строим HNSW-индекс на эмбеддингах из прошлых лекций и меряем
  recall/latency на разных параметрах.
