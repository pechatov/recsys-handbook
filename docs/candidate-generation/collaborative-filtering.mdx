# 3.2. Коллаборативная фильтрация и матричная факторизация

:::note[Черновик]
Это заглушка: ниже зафиксирован план содержания лекции. Текст будет написан
позже.
:::

## Что должно быть в лекции

- Идея коллаборативной фильтрации: похожие пользователи выбирают похожие
  айтемы; сигнал только из взаимодействий, без контента.
- Memory-based подходы: user-based и item-based KNN, меры близости,
  нормализация, shrinkage.
- Матричная факторизация: латентные факторы, модель $\hat r_{ui} = p_u^\top
  q_i$, лоссы и регуляризация, bias-члены.
- Implicit feedback: iALS — взвешивание наблюдений, confidence, почему
  нельзя просто игнорировать «нули».
- Pairwise-подходы: BPR и его вариации; сэмплирование негативов.
- Линейные модели как сильные baselines: SLIM, EASE.
- Практика: обучаем iALS и BPR на MovieLens, смотрим на соседей в латентном
  пространстве, сравниваем по метрикам из блока 1.
