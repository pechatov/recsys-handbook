# 3.5. Генеративные модели, semantic IDs и LLM

:::note[Черновик]
Это заглушка: ниже зафиксирован план содержания лекции. Текст будет написан
позже.
:::

## Что должно быть в лекции

- От дискриминативного retrieval к генеративному: модель порождает
  идентификаторы айтемов, а не скорит весь каталог.
- Semantic IDs: квантизация контентных эмбеддингов (RQ-VAE), TIGER и
  родственные подходы.
- LLM как рекомендатель: zero-shot рекомендации, дообучение на доменных
  данных, представление истории пользователя в промпте.
- LLM как инструмент вокруг системы: обогащение описаний айтемов, генерация
  фичей и эмбеддингов, контент для холодного старта.
- Диалоговые рекомендации и объяснения на естественном языке.
- Практические ограничения: latency и стоимость инференса, свежесть каталога,
  галлюцинации, оценка качества.
- Что уже используется в проде, а что пока остаётся исследованиями.
