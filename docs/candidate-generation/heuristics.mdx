# 3.1. Задача кандидатогенерации и простые генераторы

:::note[Черновик]
Это заглушка: ниже зафиксирован план содержания лекции. Текст будет написан
позже.
:::

## Что должно быть в лекции

- Постановка задачи: из миллионов айтемов быстро отобрать тысячи потенциально
  релевантных; ключевая метрика — recall кандидатов.
- Эвристические генераторы: популярное (глобально, по региону, по категории),
  новое, трендовое.
- Co-visitation и co-purchase: item-item счётчики «с этим смотрят/покупают»,
  нормализация счётчиков, окна времени.
- Кандидаты из истории пользователя: повторные покупки, продолжение
  просмотра, подписки и авторы.
- Смешивание нескольких источников кандидатов: квоты, приоритеты,
  дедупликация между источниками.
- Почему эвристики живут в проде вечно: сильный baseline, устойчивость,
  спасение при холодном старте.
- Как оценивать кандидатогенератор отдельно от всей системы: recall@K по
  будущим взаимодействиям, покрытие, пересечение источников.
