# 3.2. Двухбашенные модели и ANN-индексы

:::note[Черновик]
Это заглушка: ниже зафиксирован план содержания лекции. Текст будет написан

## Что должно быть в лекции

- Ограничения матричной факторизации: нет фичей и контекста — мотивация
  обучаемого нейросетевого retrieval.
- Архитектура two-tower: user tower и item tower, dot product / cosine;
  позднее связывание и почему кросс-фичи user × item сюда не положить.
- Обучение как extreme classification: softmax по каталогу, sampled softmax,
  in-batch negatives, logQ correction, hard negatives.
- Выбор позитивов и негативов: показы, клики, покупки, повторы; как таргет
  меняет геометрию эмбеддингов.
- Соседние семейства нейросетевого retrieval: факторизационные машины и
  автоэнкодеры (MultVAE).
- Разбор классики: YouTube DNN retrieval.
- ANN-поиск: top-K среди миллионов векторов за миллисекунды; trade-off recall
  vs QPS vs память.
- Семейства методов: LSH, графовые индексы (HNSW), инвертированные списки
  (IVF), квантизация (PQ); Faiss, ScaNN, hnswlib, векторные БД.
- Эксплуатация индекса: тюнинг параметров, обновление, свежие айтемы,
  фильтрация по атрибутам при поиске.
- Сервинг связки: предрасчёт item-эмбеддингов + онлайн-расчёт
  user-эмбеддинга + ANN.
- Практика: обучаем two-tower, строим HNSW-индекс, меряем recall/latency и
  сравниваем с матричной факторизацией.
