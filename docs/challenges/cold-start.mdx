# 7.1. Холодный старт

:::note[Черновик]
Это заглушка: ниже зафиксирован план содержания лекции. Текст будет написан
позже.
:::

## Что должно быть в лекции

- Три холодных старта: новый пользователь, новый айтем, новая система — у
  каждого своя механика и свои решения.
- Новый айтем: контентные фичи и мультимодальные эмбеддинги вместо
  коллаборативного сигнала.
- Новый пользователь: onboarding-опросы, старт с популярного, быстрая
  адаптация внутри первой сессии.
- Exploration как инструмент холодного старта: гарантированные показы новых
  айтемов (связь с лекцией 5.4).
- Гибридные схемы: плавный переход от контентного сигнала к коллаборативному
  по мере накопления данных.
- Мета-обучение и few-shot подходы — обзорно, с оценкой практической зрелости.
- Измерение: отдельные метрики и срезы для холодных пользователей и айтемов,
  time-to-first-engagement.
