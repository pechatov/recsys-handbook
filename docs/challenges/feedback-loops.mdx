# 7.3. Петли обратной связи и долгосрочные эффекты

:::note[Черновик]
Это заглушка: ниже зафиксирован план содержания лекции. Текст будет написан
позже.
:::

## Что должно быть в лекции

- Замкнутый цикл: модель формирует выдачу → выдача формирует логи → логи
  формируют следующую модель; чем это грозит.
- Наблюдаемые эффекты: гомогенизация выдачи, filter bubbles, echo chambers —
  что подтверждено исследованиями, а что преувеличено.
- Диагностика деградации со временем: метрики энтропии выдачи, доля
  «замкнутых» пользователей, офлайн-симуляции петель.
- Инструменты борьбы: exploration, разнообразие, дебиасинг, выделенный
  случайный (uniform) трафик как источник честных данных.
- Оптимизация долгосрочной ценности: LTV-прокси, surrogate-метрики,
  RL-постановка задачи.
- Reinforcement learning в рекомендациях: REINFORCE-подход YouTube, когда RL
  оправдан, а когда это оверкилл.
- Этическая рамка: удержание vs благополучие пользователя, ответственность
  платформы.
