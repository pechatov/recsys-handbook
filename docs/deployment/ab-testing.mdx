# 6.2. A/B-тестирование рекомендательных систем

:::note[Черновик]
Это заглушка: ниже зафиксирован план содержания лекции. Текст будет написан

:::

## Что должно быть в лекции

- Зачем A/B, если есть офлайн-метрики: иерархия достоверности, чем платим за
  каждый уровень.
- Дизайн эксперимента: единица рандомизации, длительность, мощность и
  минимальный детектируемый эффект.
- Статистический минимум: гипотезы, p-value, доверительные интервалы,
  множественные сравнения, подглядывание.
- Ratio-метрики и зависимые наблюдения: почему CTR — не среднее по юзерам,
  линеаризация, бакетизация.
- AA-тесты как проверка корректности статистического протокола и платформы.
- Специфика recsys-экспериментов: сетевые эффекты, взаимовлияние групп через
  общий контент и общие счётчики, novelty effect.
- Метрики эксперимента: движущие, guardrails, прокси долгосрочных эффектов;
  чувствительность метрик.
- Interleaving как чувствительная альтернатива для сравнения ранжирований.
- Инфраструктура экспериментов: слои, эксклюзивные зоны, платформа
  экспериментов как продукт.
- Интерпретация результатов: статистическая значимость vs практическая
  значимость, сегменты, неоднородность эффекта, решение ship/rollback.
- Практика: посчитать MDE, проверить AA и разобрать результат A/B с
  несколькими метриками.
