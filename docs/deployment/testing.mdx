# 6.4. Тестирование кода, данных и моделей

:::note[Черновик]
Это заглушка: ниже зафиксирован план содержания лекции. Текст будет написан
позже.
:::

## Что должно быть в лекции

- Почему рекомендательные системы ломаются тихо: деградация качества вместо
  исключений; следствия для стратегии тестирования.
- Unit- и интеграционные тесты пайплайнов обучения и сервинга; тестирование
  кода расчёта фичей.
- Тесты данных: схемы, распределения, доли пропусков, freshness — инструменты
  вида Great Expectations.
- Регрессионные тесты качества модели: golden datasets, пороги на метрики,
  сравнение с предыдущей версией.
- Тесты консистентности обучения и сервинга: ловим training/serving skew до
  прода.
- Нагрузочное тестирование и проверка деградаций/fallback-ов.
- Чек-лист выкатки изменения в рекомендательную систему: от кода до A/B.
