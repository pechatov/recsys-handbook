# Программа курса (черновик)

:::note[Черновик]
Это первый набросок программы. Состав блоков зафиксирован, набор и порядок
лекций внутри блоков будут уточняться. У каждой лекции уже есть заглушка с
планом содержания.
:::

Курс построен вокруг многоуровневой архитектуры промышленной рекомендательной
системы: сначала договариваемся, как измерять качество, затем разбираем каскад
«кандидатогенерация → ранжирование → реранкинг», потом — как это довести до
прода и какие системные проблемы приходится решать.
