# 4.1. Градиентный бустинг для ранжирования

:::note[Черновик]
Это заглушка: ниже зафиксирован план содержания лекции. Текст будет написан
позже.
:::

## Что должно быть в лекции

- Задача второго уровня: сотни кандидатов вместо миллионов айтемов, богатые
  кросс-фичи, тяжёлые модели; отличие от retrieval по требованиям.
- Learning to rank: pointwise, pairwise и listwise подходы, их лоссы и
  практические различия.
- Датасет ранкера из логов: лейблы из кликов, покупок и времени просмотра;
  негативы из показов без клика.
- Position bias в обучающих данных: постановка проблемы, позиция как признак
  и его риски, простые поправки.
- Фичи ранкера: user × item кросс-фичи, скоры и источники кандидатогенераторов,
  счётчики и CTR-фичи со сглаживанием, таргет-энкодинг без утечек.
- От RankNet к LambdaRank и LambdaMART: как оптимизировать NDCG градиентным
  бустингом.
- Практика с CatBoost / LightGBM: ranking-режимы, группировка примеров по
  показам, подбор гиперпараметров.
- Оценка: NDCG на отложенных показах, GAUC; интерпретация фичей и отладка
  ранкера на конкретных выдачах.
- Границы применимости: когда бустинг проигрывает нейросетям и наоборот.
