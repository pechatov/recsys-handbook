# 4.2. Градиентный бустинг в ранжировании

:::note[Черновик]
Это заглушка: ниже зафиксирован план содержания лекции. Текст будет написан
позже.
:::

## Что должно быть в лекции

- Почему GBDT — рабочая лошадка ранжирования: табличные фичи, скорость
  инференса, устойчивость к шуму, дешёвая итерация.
- От RankNet к LambdaRank и LambdaMART: как оптимизировать NDCG градиентным
  бустингом, интуиция лямбд.
- Практика с CatBoost / LightGBM / XGBoost: ranking-режимы, группировка
  примеров по показам, подбор гиперпараметров.
- Фича-инжиниринг для бустинга: счётчики, CTR-фичи со сглаживанием, агрегаты
  по окнам, кросс-фичи.
- Категориальные фичи и таргет-энкодинг без утечек.
- Интерпретация и отладка: feature importance, анализ ошибок ранкера на
  конкретных выдачах.
- Границы применимости: когда бустинг проигрывает нейросетям (последовательные
  сигналы, огромные словари) и наоборот.
