# 4.1. Постановка задачи ранжирования

:::note[Черновик]
Это заглушка: ниже зафиксирован план содержания лекции. Текст будет написан
позже.
:::

## Что должно быть в лекции

- Чем ранжирование отличается от кандидатогенерации: сотни кандидатов вместо
  миллионов айтемов, богатые кросс-фичи, тяжёлые модели.
- Learning to rank: pointwise, pairwise и listwise подходы, их лоссы и
  практические различия.
- Откуда берутся лейблы: клики, покупки, время просмотра, составные таргеты;
  конструирование обучающего датасета из логов показов.
- Негативы для ранкера: показы без клика, их отличие от негативов retrieval.
- Position bias в обучающих данных: постановка проблемы и простые приёмы
  (позиция как фича) — подробный дебиасинг в блоке 7.
- Фичи ранкера: user × item кросс-фичи, скоры и источники кандидатогенераторов
  как фичи, контекст запроса.
- Оценка ранкера: NDCG на отложенных показах, GAUC, связь с метриками из
  блока 1.
