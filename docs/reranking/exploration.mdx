# 5.4. Exploration в выдаче

:::note[Черновик]
Это заглушка: ниже зафиксирован план содержания лекции. Текст будет написан
позже.

## Что должно быть в лекции

- Exploitation vs exploration: зачем показывать айтемы, в которых модель не
  уверена, и кто за это платит.
- Многорукие бандиты: ε-greedy, UCB, Thompson sampling — интуиция, формулы,
  сравнение.
- Contextual bandits в рекомендациях: постановка, связь с ранжированием.
- Exploration для новых айтемов: гарантированные показы, бусты свежего
  контента, «инкубатор» (связь с холодным стартом в блоке 7).
- Логирование для будущего обучения: propensities, randomization units,
  почему exploration-трафик — ценный датасет.
- Взаимодействие exploration с A/B-метриками: краткосрочная просадка ради
  долгосрочного выигрыша.
- Кейсы: как крупные платформы раскручивают новый контент и новых авторов.
