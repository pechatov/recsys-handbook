# 5.3. Listwise-реранжирование

:::note[Черновик]
Это заглушка: ниже зафиксирован план содержания лекции. Текст будет написан
позже.
:::

## Что должно быть в лекции

- Взаимное влияние айтемов: вероятность клика зависит от соседей по выдаче;
  примеры из практики.
- Постановка: оптимизируем ценность списка или страницы целиком, а не скор
  каждого айтема по отдельности.
- Модели: seq2slate, PRM, трансформеры над списком кандидатов с фичами
  контекста выдачи.
- Данные для обучения: логи целых показанных списков, page-level фидбек.
- Whole-page optimization: страница из разнородных блоков, оптимизация
  раскладки.
- Position bias на этапе реранкинга и его учёт при обучении listwise-моделей.
- Прагматика: когда listwise даёт заметный прирост над жадной сортировкой по
  скору, а когда это лишняя сложность.
